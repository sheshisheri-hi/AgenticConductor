# Conductor Samples

## Structure

### `code-examples/`
Small code snippets for learning individual integrations:
- **ado/** — Azure DevOps code examples
- **snyk/** — Snyk vulnerability examples
- **sonar/** — SonarQube code quality examples
- **blackduck/** — BlackDuck license examples

**Usage:** Learn how each integration works, test with small inputs

### `projects/`
Complete project templates (start here):
- **hello-world/** — Minimal Conductor app (learn basics)
- **security-remediation/** — Full pipeline demo (Snyk + Code + GitHub)
- **multi-agent-workflow/** — Parallel agent execution
- **acp-integration/** — Azure Copilot integration

**Usage:** Copy and modify these to start YOUR project

See individual project READMEs for setup instructions.
