## Quick Start

### 1. Initialize a Conductor Project

```bash
# Create new project with scaffold
conductor init my-project
cd my-project

# Or initialize in existing repo
conductor init
```

This generates:
- `conductor.json` — Project manifest
- `dependencies.json` — Locked dependencies
- `config/hooks.json` — Empty (ready for compliance hooks)
- `.conductor/` — Local user config

### 2. Verify Setup

```bash
# Check everything is ready
conductor check

# Should output:
# ✓ conductor.json is valid JSON
# ✓ All dependencies verified
# ✓ Manifest is well-formed
# ✓ All critical checks passed
```

### 3. Deploy to Production

```bash
# In CI/CD pipeline, always run check first
conductor check || exit 1

# Run agents in plan mode
conductor run --plan

# If approved, execute
conductor run --execute
```

## Configuration

### conductor.json — Main Config

```json
{
  "version": "1.0",
  "name": "security-remediation",
  "description": "Auto-fix OWASP vulnerabilities",
  "agents": [
    {
      "id": "code_agent",
      "name": "CodeAgent",
      "path": "agents/code_agent.py",
      "confidence_threshold": 0.85,
      "human_gate": true
    }
  ],
  "integrations": ["snyk", "github"],
  "policies": {
    "confidence_threshold": { "value": 0.85, "locked": false },
    "strict": { "value": true, "locked": true }
  },
  "hooks": {
    "preAgentRun": [
      {
        "type": "command",
        "bash": "scripts/security-freeze-check.sh",
        "timeoutSec": 10,
        "failClosed": true
      }
    ]
  }
}
```

### Environment Variables

```bash
# Required
export CONDUCTOR_PROJECT_ROOT="/path/to/project"
export CONDUCTOR_MODE="plan"  # or "execute"

# API Keys (use .env file, never commit)
export GITHUB_TOKEN="ghp_xxxx"
export SNYK_TOKEN="snyk_xxxx"

# Optional
export CONDUCTOR_LOG_LEVEL="DEBUG"
export CONDUCTOR_AUDIT_DIR="/var/log/conductor"
```

## Secrets Management

### DO ✅

```bash
# Use environment variables
export MY_API_KEY="sk_live_xxx"

# Use .env file (never commit)
cat > .env.local << 'EOF'
GITHUB_TOKEN=ghp_xxxx
SNYK_TOKEN=snyk_xxxx
EOF

# Mark .env as secrets
echo ".env.local" >> .gitignore
echo "secrets/" >> .gitignore

# Load at runtime
from dotenv import load_dotenv
load_dotenv(".env.local")
api_key = os.getenv("MY_API_KEY")
```

### DON'T ❌

```python
# ❌ Hardcoded secrets
MY_TOKEN = "sk_live_xxx"  # NEVER!

# ❌ Secrets in config files
{
  "api_key": "ghp_xxxx"  # Will be detected and redacted by TokenScrubber
}

# ❌ Secrets in logs (TokenScrubber catches most patterns but not all)
logger.info(f"Connecting with token {token}")  # High risk
```

## Token Scrubbing

### What Gets Scrubbed

| Pattern | Example | Scrubbed |
|---------|---------|----------|
| GitHub token | `gh_pou_1234...` | ✅ `[REDACTED_GITHUB_TOKEN]` |
| AWS access key | `AKIA1234...` | ✅ `[REDACTED_AWS_KEY]` |
| Bearer token | `Bearer eyJhbGc...` | ✅ `Bearer [REDACTED_TOKEN]` |
| Database password | `password: "secret"` | ✅ `password: [REDACTED]` |
| JWT | `eyJhbGc.eyJsc...` | ✅ `[REDACTED_JWT]` |

### Enable Scrubbing

```python
from conductor_core.secrets import install_scrubber

# Install globally
install_scrubber()

# Now all logs are scrubbed automatically
import logging
logger = logging.getLogger(__name__)
logger.info(f"Token is {token}")  # Token is [REDACTED]
```

### Add Custom Patterns

```python
from conductor_core.secrets import TokenScrubber, ScrubPattern

scrubber = TokenScrubber(patterns=[
    ScrubPattern(
        name="my_api_key",
        pattern=r"x-api-key['\"]?\s*:\s*['\"]?([a-z0-9]{32})",
        replacement="x-api-key: [REDACTED]"
    ),
    # Use default patterns too
    *TokenScrubber.DEFAULT_PATTERNS,
])
```

## Dependency Verification

### Verify at Startup

```python
from conductor_core.manifest.dependencies import DependencyVerifier
from pathlib import Path

verifier = DependencyVerifier(Path("dependencies.json"))
is_valid, issues = verifier.verify()

if not is_valid:
    logger.critical(f"Dependency mismatch: {issues}")
    sys.exit(1)  # Block execution
```

### In CI/CD Pipeline

```yaml
# GitHub Actions example
- name: Verify dependencies
  run: |
    conductor check || exit 1

- name: Run agents
  run: |
    conductor run --plan
```

### Update Locked Dependencies

```bash
# When you add/remove packages
pip install new-package

# Regenerate lock file
conductor init --force

# Review changes
git diff dependencies.json

# Commit
git add dependencies.json
git commit -m "Update locked dependencies"
```

## Schema Validation

### Define Expected Output

```python
from pydantic import BaseModel
from conductor_core.decorators import validated_agent

class CodeGenOutput(BaseModel):
    code: str
    language: str
    confidence: float
    explanation: str

@validated_agent(CodeGenOutput, raise_on_invalid=True)
async def code_agent_run(self, context):
    # Return must match schema
    return {
        "code": "def hello(): return 'world'",
        "language": "python",
        "confidence": 0.98,
        "explanation": "Simple function"
    }
```

### Register Schemas

```python
from conductor_core.validation import register_schema

register_schema("code_agent", CodeGenOutput)
register_schema("security_agent", AnalysisOutput)

# View all registered schemas
from conductor_core.validation import list_schemas
print(list_schemas())
```

### Batch Validation

```python
from conductor_core.decorators import AgentOutputValidator

validator = AgentOutputValidator()

# Validate multiple outputs
results = [
    validator.validate("code_agent", code_output, CodeGenOutput),
    validator.validate("security_agent", sec_output, AnalysisOutput),
]

# Get summary
summary = validator.get_summary()
print(f"Validated {summary.successful}/{summary.total_validated}")
```

## Audit Logging

### Enable Audit Logs

```python
import logging
from conductor_core.secrets import install_scrubber

# Setup logging with scrubbing
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    handlers=[
        logging.FileHandler("/var/log/conductor/audit.log"),
        logging.StreamHandler()
    ]
)

# Install scrubber filter
install_scrubber()
```

### What Gets Logged

```

2026-06-04 12:34:57 - conductor.agent - INFO - CodeAgent started
2026-06-04 12:34:58 - conductor.secrets - DEBUG - Scrubbed token: [REDACTED_GITHUB_TOKEN]
2026-06-04 12:35:00 - conductor.agent - INFO - CodeAgent completed: confidence=0.95
2026-06-04 12:35:01 - conductor.orchestrator - INFO - Run completed: run_id=xyz-123, status=success
```

### Export Audit Trail

```bash
# Get full trace for a run
conductor export run_id --format json > audit_xyz.json

# Share with stakeholders (no secrets)
conductor export run_id --format html > report.html
```

## Health Checks

### Pre-Deployment Checklist

```bash
# 1. Verify environment
conductor env

# 2. Run all checks
conductor check

# 3. Verify dependencies
conductor check --json | jq '.failed_count'

# 4. Validate config
conductor validate conductor.json

# 5. Test in plan mode
conductor run --plan --dry-run
```

### Monitoring

```bash
# Check logs for errors
tail -f /var/log/conductor/audit.log | grep "ERROR\|CRITICAL"

# Monitor token scrubbing
tail -f /var/log/conductor/audit.log | grep "\[REDACTED"

# Alert if dependency check fails
conductor check || send_alert "Conductor health check failed"
```

## Troubleshooting

### "conductor.json not found"

```bash
# Generate scaffold
conductor init

# Or copy from template
cp config/conductor.json.template conductor.json
```

### "Dependency verification failed"

```bash
# Check what changed
conductor check --json | jq '.details.failed'

# Regenerate manifest
conductor init --force

# Review changes
git diff dependencies.json

# Or pin specific versions in pyproject.toml
# then regenerate
```

### "Validation failed: ..."

```bash
# Enable debug logging
export CONDUCTOR_LOG_LEVEL=DEBUG
conductor run --plan

# Check schema mismatch
conductor export run_id --format json | jq '.agent_output'
```

### "Token scrubbing not working"

```python
# Check if scrubber is installed
from conductor_core.secrets import TokenScrubber
scrubber = TokenScrubber()
text = "My key is sk_live_xxx"
print(scrubber.scrub_text(text))  # Should show [REDACTED]

# Add custom pattern if needed
from conductor_core.secrets import ScrubPattern
# ... (see Token Scrubbing section)
```

## Security Best Practices

### 1. Always Use Plan Mode First

```bash
conductor run --plan   # Safe: shows what would happen
conductor run --execute  # Dangerous: actually makes changes
```

### 2. Enable Human Gates for Destructive Operations

```json
{
  "agents": [
    {
      "id": "code_agent",
      "human_gate": true  # Requires approval
    }
  ]
}
```

### 3. Regularly Verify Dependencies

```bash
# In CI/CD: run before every execution
conductor check || exit 1
```

### 4. Rotate Secrets Regularly

```bash
# Update credentials
export GITHUB_TOKEN="ghp_new_token"

# Regenerate dependencies (if auth-based scanning changed)
conductor init --force

# Restart agents
```

### 5. Monitor Audit Logs

```bash
# Watch for unusual activity
tail -f /var/log/conductor/audit.log

# Alert if scrubber detects too many secrets
grep "\[REDACTED" /var/log/conductor/audit.log | wc -l
```
